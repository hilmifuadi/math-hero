# Sumber aset MH4 v2

Disiapkan oleh `scripts/prepare_assets_mh4.js` dari paket di `games/assets/itch.io free resourcepack`.

| Pemakaian | Paket | Lisensi menurut berkas paket |
|---|---|---|
| Arka, tengkorak, lendir, peti, tanah, tanaman, hewan, rumah, pagar | Cute Fantasy Free | Non-komersial, boleh diubah, dilarang disebarkan ulang |
| Kasur | Mystic Woods Free | Non-komersial, boleh diubah, dilarang disebarkan ulang |
| Warga | Pipoya Free RPG Character Sprites | Tidak ada berkas lisensi di paket |
| Air mancur | EPIC RPG World Pack Ancient Ruins (demo) | Tidak ada berkas lisensi di paket |
| Landasan tempa, orang-orangan sawah | Pixel Crawler Free | Boleh komersial, kredit tidak wajib, aset tidak boleh dijual |
| Lantai dan perabot rumah | Top-Down Retro Interior | Tidak ada berkas lisensi di paket |
| Papan kayu, bar, ikon | Medieval UI Free | Tidak ada berkas lisensi di paket |
| Peluru boss | Effect and Bullet 16x16 | Tidak ada berkas lisensi di paket |

Visual platformer di `world/` dibuat `scripts/prepare_world_mh4.js`: tekstur batu dan dekor dari Pixel
Crawler, pohon dari pixel_16_woods, peti kayu dari Mystic Woods, lampu dan kristal dari Cute Fantasy.
Latar, tutup tanah, platform, duri, bintang, bendera, dan gerbang digambar oleh kode.

Paket sumber tidak disalin utuh; hanya berkas yang dipakai game. Paket tanpa berkas lisensi dianggap
bebas dipakai atas keputusan pemilik proyek (2026-11-05). Cara membuat ulang ada di README bagian
"Aset Math Hero 4".
